# Java Programming Practice

Java fundamentals and programming exercises supporting my test automation work.

## Explore the code

- `src/main/java/`: Java examples, including interfaces, collections and programming fundamentals.
- `pom.xml`: Maven project configuration.

## Run an example

Import this repository as a Maven project into a Java IDE. Open the class you want to explore, review its inputs and dependencies, and run its entry point. Each exercise can be studied independently.
